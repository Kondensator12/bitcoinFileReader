# bitcoinDataReader
Reads and translates binary bitcoin file data to human readable text

For now you can only get a terminal output with block header information

Works for block version 2. Tested for blk00050.dat - blk00077.dat 

How to install:

1.) get the repo via git clone

2.) create a folder for the build

3.) cmake (repo folder)

4.) ./app/main path1 path2

path1 = path of the blk file

path2 = path of the xor file
